# 私人声音出版台实施计划

日期：2026-08-11

## 目标

在不改变项目数据格式、不更换语音模型的前提下，把现有朗读项目界面重组为声音作品工作台，并补齐直接导出到用户所选位置的能力。

## 实施步骤

1. 增加纯数据的出版阶段摘要，覆盖原稿、朗读稿、声音片段和三种成品状态，并写自检。
2. 在工作区模型增加安全的现有成品复制接口；缺失格式、错误扩展名和复制失败必须有明确状态。
3. 新增四阶段出版轨道 SwiftUI 组件，使用文字、图标和颜色共同表达状态。
4. 重组作品编辑页：新作品展开来源；已有分段作品折叠来源；结果、播放、编辑和交付前移。
5. 将“高级编辑”改为“编辑作品”，保留逐段编辑默认折叠，并强化“只重做这一段”的说明。
6. 在成品卡新增格式化导出菜单和原生保存面板，默认文件名来自项目名称。
7. 将主要用户可见词汇由“朗读项目／我的听读”改为“声音作品／作品库”，不迁移内部类型和本地数据。
8. 运行全部自检、便携构建、签名和最低系统版本检查。
9. 启动成品应用进行键盘/无障碍树和实际界面复审；发现影响主流程的问题后修正并重新验证。

## 回滚边界

- 所有变化只在当前 Git 仓库内；
- 不删除用户项目或音色；
- 不修改 `NarrationProject.currentFormatVersion`；
- 不升级系统、不安装系统依赖；
- 若新界面构建失败，可单独回退 UI 提交，不影响已有本地数据。
