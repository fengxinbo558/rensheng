# 渐进式声音质量版本实施计划

## 实施约束

- 不升级 macOS，不安装系统组件。
- 不引入新的正式模型或云端依赖。
- 旧音色、旧项目和既有音频继续可用。
- 主界面只保留正常流程所需操作；实验与诊断能力不进入默认层。

## Task 1：修复声音质量链路

1. 为音色增加“合成参考录音”自动选择：干净录音使用原始版，明显底噪使用清理版。
2. Qwen 输出取消固定 50% DeepFilter 混合，保留峰值保护和完整性检查。
3. 更新录音界面说明；爆音或音量过低时不允许保存。
4. 扩展音色与引擎配置自检。

## Task 2：把项目主流程合并为一次操作

1. 新增“准备并生成”入口，自动完成分析、保存和继续生成。
2. 全文成功后自动制作 WAV、M4A 和 MP3。
3. 已有成品再次点击时不重复合成。
4. 保持暂停、恢复和失败重试。

## Task 3：实现渐进式高级编辑

1. 项目名称、全文语速和段落控制默认折叠。
2. 增加段落朗读文字修正。
3. 增加单段重新生成，只运行目标段并保留旧候选。
4. 增加候选版本选择，切换后只需重做最终拼接。

## Task 4：简化快速生成和音色录入

1. 生成引擎和兼容质量移入“高级设置”。
2. 音色原始／清理试听和删除移入菜单。
3. 推荐朗读稿默认只读，修改入口折叠。
4. 更新所有用户可见文案，避免暴露内部模型与降噪细节。

## Task 5：验证与交付

1. 扩展 GenerationQueue、VoiceLibrary 和项目模型自检。
2. 运行全部 Swift 自检、Python runner smoke、开发构建和便携构建。
3. 深度校验签名，检查应用包不包含开发机绝对路径。
4. 使用便携应用运行真实短句生成，记录耗时、内存、音频完整性和保存路径。
5. 启动最终应用并进行界面烟雾检查。
