# 声音导演 UI 重设计

## 目标

让桌面应用第一眼像一个轻量、可信的音频工作台：用户能在一个屏幕内看懂“导入内容 → 编辑原稿 → 选择音色 → 生成/播放”，同时保留作品库、断点生成和导出能力。

## 视觉方向

- 采用浅色纸张式画布，避免 macOS 深色模式把默认文字变成白色；应用固定使用浅色外观。
- 颜色使用暖白画布、冷灰分区、深蓝主操作色、薄荷绿完成状态；危险操作仅使用红色。
- 文字层级收敛：品牌眉题、页面标题、说明文字、数据标签四级，不再使用过大的宣传式标题。
- 卡片减少透明叠加，统一圆角与边框，降低视觉噪声。

## 布局

- 左侧作品库固定窄栏：产品标识、作品数量、新建按钮、作品列表。
- 右侧编辑区：小型标题区、内容导入卡、原稿编辑区、音色与生成操作栏。
- 已有作品增加出版进度和播放器，但将播放器作为主要结果卡片，不与编辑内容争夺首屏注意力。
- 输入区高度控制在约 190–220pt；空状态给出明确下一步，不保留过大的空白区域。

## 行为与兼容性

- 不改变导入、项目保存、音色、生成、播放、速度和导出逻辑。
- 只调整 SwiftUI 视图层和样式；现有自检继续作为回归门槛。
- 保留无障碍标签、键盘焦点和现有中文文案语义。

## 验收标准

1. 深色系统外观下，应用仍显示可读的浅色界面。
2. 新建项目首屏能看到导入、原稿、音色和生成四个关键动作。
3. 已有项目的进度、播放器、编辑和导出入口仍可访问。
4. 自检通过，便携应用可编译并正常启动。
