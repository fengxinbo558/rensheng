# 渐进式声音质量版本设计

## 1. 目标

把现有离线普通话桌面原型收缩成一版“外简内繁”的可用产品：普通用户只需选择音色、粘贴文字并点击生成；声音质量、设备适配、分段、失败恢复和音频处理由应用内部完成。只有用户遇到问题或主动进入高级编辑时，才显示局部语气、语速、停顿、候选版本和重新生成等控制。

本版本继续保持完全离线，不升级 macOS，不安装或修改系统组件。

## 2. 产品原则

1. 正常流程最多包含三个主动决策：选音色、贴文字、开始生成。
2. 能自动判断的技术决策不交给用户；模型名、采样参数、内存档位、降噪算法和内部重试不出现在主界面。
3. 高级能力按需展开。默认界面只显示输入、生成、播放和导出；段落级控制集中在“高级编辑”。
4. 不制造虚假控制。只有确实改变生成或成品的设置才显示为可调选项。
5. 声音质量按“自然度第一、音色相似度第二、情感表现第三”排序，同时保持能辨认出同一说话人的底线。

## 3. 失败预演与收缩结论

### 3.1 主界面被实验功能占满

如果把模型赛马、音量对齐、内存档位和音频处理全部交给用户，第一次使用就会要求理解大量技术概念，用户在生成第一段声音前失去耐心。

**缓解：** 模型比较只作为开发工具；正式产品只展示用户能凭偏好判断的选择。主界面不出现模型名和音频算法。

### 3.2 固定降噪制造电子感

当前自然人声链路优先使用原始参考录音，同时对所有输出固定混入 50% DeepFilter 结果。无论输入是否有噪声都处理，可能损伤气息和高频细节，使用户听到“电流感”或“塑料感”。

**缓解：** 参考录音根据质量报告选择原始或清理版本；高质量原录音保留细节，明显底噪录音使用清理版。模型输出默认保持干声，只做削波保护，不固定降噪。

### 3.3 表达选项只是界面标签

当前段落表达会进入项目指纹，却没有进入自然人声生成请求。用户修改“亲切”或“强调”后会等待重新生成，但模型没有得到对应条件。

**缓解：** 默认界面不突出表达选择。当前版本保留可验证的节奏和停顿处理；真正的多风格参考录音作为后续高级音色能力，不用随机参数冒充情感控制。

### 3.4 为每个用户打包多个模型

同时集成多个大模型会迅速扩大安装包，增加 8GB 设备压力和维护面，而用户只关心哪个声音更好听。

**缓解：** 多模型匿名比较只在研发阶段进行。正式应用只打包已验证的主模型和必要兼容引擎，不提供模型赛马界面。

### 3.5 只在 32GB 开发机上验证

如果把人为限制内存当成真实低配证据，应用可能在 M1 8GB 上被系统终止，造成项目中断和信任损失。

**缓解：** 本版本保持逐段串行、可暂停和可恢复；在真实 8GB/16GB 设备完成测试前，只标记为候选兼容，不宣称正式支持。

## 4. 默认用户流程

1. 用户选择已有音色，或录制 10～30 秒参考音频。
2. 用户粘贴 3000 字以内的普通话内容。
3. 用户点击一次“生成音频”。应用自动保存项目、分析结构并逐段生成。
4. 生成完成后，应用自动制作 WAV、M4A 和 MP3 成品。
5. 用户直接播放或在访达中打开成品。

项目名称、全文语速、段落细节和重新生成放入高级区域，不阻塞正常流程。

## 5. 渐进式界面

### 5.1 默认层

- 音色选择与“录入新音色”。
- 文章输入框与字数。
- 单一主按钮“生成音频”。
- 生成进度、播放控制和“在访达中显示”。

### 5.2 高级编辑层

默认折叠，用户主动展开后显示：

- 项目名称与全文成品语速。
- 各段朗读文字修正。
- 每段语速、段后停顿和表达提示。
- 单段重新生成。
- 多候选版本选择。

### 5.3 设置与诊断层

兼容引擎、缓存、运行信息和音频诊断不进入主流程。错误发生时优先给出“重试”“继续生成”或“使用兼容模式”等动作，不只展示技术原因。

## 6. 声音质量链路

### 6.1 参考录音

- 始终保存原始转换录音和清理录音。
- 录音质量良好时，合成优先使用原始版本，避免不必要的降噪伪影。
- 检测到明显环境底噪时，合成使用清理版本。
- 爆音或音量过低属于不可可靠修复的问题，录入界面要求重录。

### 6.2 模型输出

- Qwen 输出默认不经过固定 DeepFilter 混合。
- 保留重采样、有限峰值保护、完整性和削波检查。
- 输出失败只重试当前段，不删除项目、原文或已完成音频。

### 6.3 分段与连续性

- 维持 100 字左右的语义片段和 120 字硬上限，兼顾连续感、低配内存和局部恢复。
- 同类相邻句自动合并；标题和结论保持独立。
- 最终拼接统一停顿和成品语速，不用全局强降噪掩盖片段差异。

## 7. 数据与状态

- 旧项目和旧音色必须继续可读。
- 每段保留多个音频候选和当前选中版本。
- 重新生成单段时保留旧候选；用户可以无损切回。
- 修改朗读文字会使该段旧候选失效，但不影响其他段。
- 全文生成完成后自动生成三种标准格式；任一段设置变化只让成品导出失效。

## 8. 错误处理

- 模型不可用：自动使用现有兼容引擎，或给出单一可执行恢复动作。
- 生成被取消：已完成段落保留，下次从未完成段继续。
- 输出无效：自动换种子重试一次，第二次失败后停止在该段。
- 磁盘或参考录音缺失：保留项目资料，不自动删除任何内容。
- 极端成品语速：只在高级编辑中提示拉伸感风险。

## 9. 验收标准

### 9.1 交互

- 新用户创建好音色后，从粘贴文章到开始生成不超过三个主动操作。
- 默认界面不出现模型名、种子、降噪强度、内存档位或质量实验。
- 高级编辑默认折叠，展开后可以修正文字、重做单段和选择候选。

### 9.2 功能

- 一次主操作完成分析、项目保存和全文生成。
- 成功生成后自动制作 WAV、M4A 和 MP3。
- 单段重做只生成目标段并保留旧候选。
- 候选切换后重新拼接成品，无需重新合成语音。
- 播放、暂停、停止、进度跳转和 0.1～3.0 倍速继续可用。

### 9.3 质量与稳定性

- 新录音根据质量自动选择原始或清理参考。
- Qwen 输出不再固定混入 50% 降噪结果。
- 自检、开发构建、便携构建、签名校验和真实短句生成全部通过。
- 真实 8GB/16GB 兼容结论仍需对应设备证据；本机测试不能替代。

## 10. 明确不做

- 不在正式界面加入多模型匿名赛马。
- 不加入视频、网页链接、字幕提取、语音转写或笔记同步。
- 不接入默认云端生成。
- 不用随机采样参数冒充可控情感。
- 不强迫用户每次全文生成前比较多个预览。
- 不升级 macOS，不安装系统级运行环境。
