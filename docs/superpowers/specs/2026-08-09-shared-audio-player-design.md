# 统一音频播放器与成品失效设计

- 日期：2026-08-09
- 范围：朗读项目、快速生成、音色试听、成品语速
- 约束：完全本地处理，不安装或修改 macOS 系统组件

## 1. 问题与目标

当前界面只有“播放”动作，没有暂停、继续、停止和进度信息。“暂停生成”与音频播放无关，但名称容易让用户误以为它也能控制播放。项目内容或朗读设置变化后，旧成品仍显示为就绪，也会让用户误听过期结果。

本次目标是建立一个全应用共用的播放器，让用户在生成前后都能明确控制正在播放的音频，并确保界面不会把旧成品标记为最新成品。播放器和成品制作均支持 `0.1×...3.0×`、步长 `0.1×` 的保持音高变速。

## 2. 采用方案

新增单一的 `PlaybackController`，使用 `AVAudioEngine + AVAudioPlayerNode + AVAudioUnitTimePitch`，集中持有播放来源、播放状态、当前时间和总时长。朗读段落、朗读成品、快速生成结果、音色参考录音都交给它播放，任一新音频开始时自动停止上一条。

试听和离线成品变速使用 macOS 原生 `AVAudioUnitTimePitch`。它将速度与音高分开处理，不采用会同时改变音高的简单重采样，也不为了改速度而重新调用语音模型。

播放器状态：

- 未载入：没有可控制的音频。
- 播放中：显示“暂停”和“停止”。
- 已暂停：显示“继续”和“停止”，保留当前位置。
- 已结束或已停止：回到起点，显示“播放”。
- 失败：停止并显示中文错误，不保留假播放状态。

速度分为两个互不混淆的值：

- 成品语速：保存在项目和段落中，制作 WAV、M4A、MP3 时真正写入文件。
- 试听速度：只影响当前播放器，默认 `1.0×`，不会偷偷修改项目和导出结果。

## 3. 界面行为

### 朗读项目

- “成品播放器”固定显示播放／暂停、停止、可拖动进度条、当前时间和总时长。
- 播放器提供 `0.1×...3.0×`、步长 `0.1×` 的试听速度控件。
- 每个已完成段落仍有快捷播放按钮；点下后，下方播放器立即切换为“第 N 段”。
- 全文仍在生成时，已经完成的段落可以立即播放；正在生成或尚未生成的段落保持禁用。
- “暂停生成”保留该完整名称，播放器使用“暂停播放”，两者不混用。
- “全文语速”默认 `1.0×`，调整后可一键应用到所有段落。
- 每个段落显示紧凑的数值语速控件，可以在全文默认值上单独微调。

### 快速生成与音色试听

- 快速生成结果和音色参考录音复用相同的播放／暂停／停止行为。
- 切换到另一段音频时停止上一条，避免两个声音重叠。
- 快速生成和参考音色可以临时改变试听速度，但原始文件保持不变。

### 成品失效

- 修改原文、音色或表达方式后，对应段落标记为需要重新生成，并清空导出记录。
- 只修改成品语速或段后停顿时，保留已经生成的段落母版，仅清空导出记录并提示重新制作成品。
- 旧文件不自动删除；再次制作成品时原子覆盖同名文件，避免不可恢复的数据删除。
- 只要仍有未完成段落，旧成品不再显示“已就绪”，也不能通过播放器误播放。

## 4. 成品语速与旧项目迁移

- 新项目的全文和段落成品语速默认都是 `1.0×`。
- 段落数据新增 `speedFactor: Double`；全文语速控件是批量修改所有段落，不额外保存第二个可能冲突的全局速度值。
- 允许范围为 `0.1×...3.0×`，保存前统一按一位小数取整并限制在范围内。
- 低于 `0.6×` 或高于 `2.0×` 时显示“极端速度可能出现明显拉伸感”，但不禁止用户使用。
- 旧项目中的“稍慢／正常／稍快”分别迁移为 `0.9×／1.0×／1.1×`，不要求重新录音。
- 语音模型输出的段落 WAV 始终保留原速；拼接前逐段做保持音高变速，再进行淡入淡出、音量统一和停顿插入。
- 成品预计时长按每段 `原时长 ÷ 成品语速 + 段后停顿` 计算，极慢速度制作时界面提前显示预计时长。

## 5. 组件边界

- `PlaybackController`：加载、播放、暂停、继续、停止、拖动、时间更新和播放完成回调。
- `PlaybackControlsView`：纯界面组件，只读取播放器状态并发送控制动作。
- `AudioTimeStretcher`：使用系统音频单元离线处理单段 WAV，保持音高并按目标时长输出。
- `NarrationWorkspaceModel`：决定要播放哪个项目文件，不再直接管理 `AVAudioPlayer`。
- `ProbeViewModel`：负责生成与文件位置，不再创建自己的播放器。
- `ProjectPlayerBar`：显示当前来源、进度和控制按钮，并提供访达入口。

## 6. 数据与错误处理

- 拖动进度限制在 `0...duration`；空文件、损坏文件和路径失效时拒绝播放。
- 播放计时器只在播放时运行，暂停、停止、完成和对象释放时立即取消。
- 项目切换、删除或重新分析时停止当前项目音频，防止继续播放已离开的内容。
- 导出失效只更新项目 JSON 引用，不删除段落母版和旧成品文件。
- 单段变速失败时停止成品制作，保留所有原始段落母版和上一份旧文件，不留下半成品。
- 极慢速度按段处理并写入临时文件，避免一次把整篇扩展音频放进内存。

## 7. 辅助功能

- 控件使用明确中文标签：“播放”“暂停播放”“继续播放”“停止播放”“播放进度”。
- 进度条提供“已播放 X，音频共 Y”的辅助功能值。
- 播放来源通过文字和辅助功能状态同时呈现，不只依赖图标或颜色。
- 全文和段落语速控件读作“成品语速 0.9 倍”，试听控件读作“试听速度 1.2 倍”。

## 8. 验收标准

1. 成品播放后按钮变为“暂停播放”，暂停后变为“继续播放”，停止后回到起点。
2. 拖动进度条后从新位置继续播放，时间显示同步更新。
3. 生成过程中可以播放任一已完成段落，且不影响后台继续生成。
4. 新播放会停止旧播放，不出现两条音频重叠。
5. 修改任一会影响音频的设置后，旧成品不再显示为最新成品。
6. 朗读项目、快速生成、参考音色三处控制语义一致。
7. 成品语速和试听速度都能在 `0.1×...3.0×` 间按 `0.1×` 调整。
8. `0.5×` 成品时长约为原来的两倍，`2.0×` 成品时长约为原来的一半，音高不随速度成比例变化。
9. 只改语速或停顿不会重新调用语音模型，但会要求重新制作成品。
10. 旧项目速度迁移正确，现有项目存储、生成恢复、三格式导出和便携构建测试继续通过。
